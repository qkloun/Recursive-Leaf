#  🌿 Recursive Fractal Tree

A Python implementation of a beautiful fractal tree pattern using recursive algorithms and turtle graphics.

## 📋 Overview

This project creates an organic, leaf-like fractal pattern using recursive branching. The algorithm mimics natural tree growth by creating progressively smaller branches at each recursion level, resulting in a visually appealing plant structure.

## ✨ Features
- **Pure Recursion** - Elegant recursive implementation
- **Configurable Depth** - Adjustable recursion levels for detail control
- **Natural Branching** - 45° angles create realistic tree structure
- **Smooth Rendering** - Optimized with turtle tracer for instant display
- **Parametric Design** - Customizable length and depth

## 📦 Requirements
- Python 3
- turtle (included in Python standard library)
